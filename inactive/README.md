# Inactive

Curated public-safe workflow assets that are intentionally **not live**.

Nothing under `inactive/` is synced by `sync.sh`, loaded by a harness, or normative for current work. Keep an item here only when it is no longer used but is still useful enough to preserve for possible reactivation.

Before moving anything back to `live/` or `templates/`, review it against the current harness capabilities and workflow contract. Do not treat inactive content as current configuration.
