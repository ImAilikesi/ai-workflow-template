# Sticky Rules

- Do not commit, push, merge, deploy, publish, spend, send external messages, use secrets, or perform destructive or irreversible actions unless the operator explicitly authorizes that exact action and target.
- Never edit `.env`, credentials, tokens, private keys, or private data unless explicit authority requires it.
- Use only OMP built-in agents or explicitly configured custom agents. Do not invent ad-hoc roles or silently substitute another model/provider.
- A review verdict never authorizes implementation, version-control mutation, deployment, spend, secret use, destructive action, or external mutation.
- Explicit operator routing or model selection overrides defaults for the requested work.
